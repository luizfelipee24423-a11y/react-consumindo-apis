# React - Consumo de APIs

Projeto desenvolvido para praticar integração de aplicações React com APIs REST.

## APIs utilizadas

- ViaCEP
- PokeAPI

## Conteúdos praticados

- React
- useState
- useEffect
- Fetch API
- async/await
- JSON
- tratamento de erros com try/catch
- response.ok
- renderização de listas com map()
- organização de chamadas HTTP em services
- componentes e Props
- CSS básico

## Funcionalidades

- Consulta de endereço através do CEP
- Busca individual de Pokémon
- Exibição da imagem do Pokémon
- Carregamento de uma lista de Pokémons
- Tratamento de erros
- Mensagem de carregamento
- Exibição de produtos simulados com componentes reutilizáveis
